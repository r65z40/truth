# Images remplaçables

Fonds d'écran et illustrations déclarés dans `data/images.json` (menu, bureau,
introduction, soirées, fin d'acte). Noms attendus, tailles conseillées et
replis : `docs/MEDIAS.md`. Un fichier absent n'est pas une erreur : l'écran
garde son dessin ou son fond uni. Extension libre : `.png`, `.webp` ou `.jpg`.
