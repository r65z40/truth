# Sons : ambiances et bruitages

- `ambiances/` : boucles de fond (pluie, bureau, appartement...).
- `effets/` : sons brefs (clic, tampon, machine à écrire, papier...).

Les noms de fichiers attendus et le moment où chacun joue sont dans
`data/sounds.json` (champ `usage`) et dans `docs/MEDIAS.md`. Un fichier absent
donne du silence. Extension libre : `.ogg`, `.wav` ou `.mp3`.
Pour voir ce qui manque : Visite des scènes > OUTILS > Médias.
